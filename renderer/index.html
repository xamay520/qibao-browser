vpngate 免费节点使用步骤（小白看这里）
  1. 点击上方"去 vpngate 拿免费节点"打开列表页
  2. 在表格里向右滚动，找到名为 Socks 的那一列（位置在 SSL-VPN / L2TP / OpenVPN / SSTP 之后）
  3. 认准 Socks 列里有数字（如 1080 / 1295 / 1296）的行——那才是浏览器能用的 SOCKS5 代理
  4. 把该行 DNS 填"主机"、Socks 列里那个数字填"端口"——千万别填 SSL-VPN / OpenVPN 列下的 443，那是 OpenVPN 端口浏览器用不了
  5. 类型选 SOCKS5，用户名密码填 vpn / vpn（点上方按钮自动帮你填好）
  6. 保存启动后访问 ip.sb，看到显示节点 IP = 成功；显示你本机 IP = 端口类型不对，回表重选

vpngate 免费节点 24h 轮换、人多会慢，多存几个备用。详细说明见随附文档 VPNGATE.md。
